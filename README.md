# Diseñador de catálogo DRENHISA

Abre `index.html` en Chrome (doble clic). No requiere instalación.

- **Página de producto**: título con palabras en color (`[[Agua Potable]]`), descripción, usos, tabla, listas de medidas, fotos y textos grandes arrastrables.
- **Página con varios artículos**: foto + nombre + lista de medidas por artículo; las columnas se calculan solas.
- Medidas: escribe `1/2`, `2 1/2` y se convierten a ½”, 2½”. Con valor: `1 | 50mts y 100mts`.
- Avisa si el contenido se sale de la página.
- Se autoguarda en el navegador; usa **Guardar archivo** / **Abrir…** para respaldo.
- **Exportar PDF** → en el diálogo de impresión elige "Guardar como PDF", tamaño Carta, márgenes ninguno, y activa "Gráficos de fondo". El PDF se puede subir a Canva.
